# Code of conduct

This repository follows Longboard's:
[CODE_OF_CONDUCT.md](https://github.com/AndrewGBest/Longboard/blob/main/CODE_OF_CONDUCT.md).
In short: be direct and be kind, criticise the work and not the person, and
tell the maintainer, [@AndrewGBest](https://github.com/AndrewGBest), if
something goes wrong.

# Security

Profiles are data: Longboard's validator refuses a profile that carries code
or a key it does not know. If you find a way for a profile to do something
it should not, or a problem in a published profile that could put people at
risk, please report it privately:
[open a private advisory](https://github.com/AndrewGBest/Longboard-Profiles/security/advisories/new).

Problems in Longboard itself go to
[its security policy](https://github.com/AndrewGBest/Longboard/blob/main/SECURITY.md).
